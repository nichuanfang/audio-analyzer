# Music Analyzer

自建音乐特征分析服务，基于 Essentia 提取音频的节奏、调性与舞性指标，通过 FastAPI 提供 REST 接口。

---

## 指标说明

### 1. BPM（速度）

- **含义**：Beats Per Minute，每分钟拍数，表示音乐速度。
- **典型范围**：40 – 240 bpm（常见音乐）
- **常见体裁与 BPM**：

| BPM 范围       | 常见体裁 / 场景                     | 听感描述                     |
|---------------|------------------------------------|------------------------------|
| 40 – 60       | 氛围音乐、冥想音乐                 | 极慢、沉静、空灵             |
| 50 – 80       | 抒情 Ballad、慢速民谣              | 慢、叙事感强、情感内敛       |
| 60 – 90       | Dub、慢摇、民谣                    | 慢、重低音、节奏舒缓         |
| 60 – 100      | Hip-hop                            | 中慢、律动明显               |
| 80 – 120      | Funk / R&B / Country               | 轻快、有律动感               |
| 90 – 120      | 流行舞曲、Rap                      | 中快、节奏清晰               |
| 90 – 140      | Rock                               | 中快、有力度                 |
| 115 – 130     | House                              | 标准电子舞曲速度             |
| 120 – 140     | Techno / Trance / 流行电子         | 快、有能量、适合舞池         |
| 135 – 145     | Dubstep                            | 极快、重拍、节奏强烈         |
| 140 – 180     | Metal                              | 非常快、高强度               |
| 160 – 180     | Drum and Bass                      | 极快、节奏密集               |

> 医学上的 BPM 是心率（60–100 次/分钟），与音乐速度 BPM 不同概念。

---

### 2. BPM Confidence（节拍检测置信度）

- **含义**：BPM 估计的可靠程度。
- **Essentia 范围**：理论上是 0 – 1，但 ESS 内部可能输出 >1 的“score”，越大越可靠,小于0.3不可靠。
- **解读**：值越大，表示 BPM 估计越可信。

---

### 3. Danceability（舞性）

- **含义**：音乐是否适合跳舞，综合节拍稳定性、律动、速度和拍点强度。
- **Essentia 范围**：约 **0 – 3**，越高越适合跳舞 [web:32]。
- **场景分类**：

| Danceability | 场景 / 体裁                              | 听感描述                         |
|-------------|------------------------------------------|----------------------------------|
| 0 – 0.5     | 氛围音乐、慢速抒情、实验音乐             | 几乎不适合跳舞                   |
| 0.5 – 1.0   | 慢摇、慢速民谣、部分嘻哈、慢 R&B         | 低–中等舞性，可跟拍但不强        |
| 1.0 – 1.5   | 流行电子、轻舞曲、中速 House、轻摇滚     | 中等偏上，适合派对/舞池跟拍      |
| 1.5 – 2.0   | 典型 Club 音乐、House、Techno            | 高舞性，适合跳舞                 |
| 2.0 – 3.0   | Dubstep、Drum and Bass、高强度舞曲       | 极高舞性，适合狂舞/密集节奏场景  |

> Spotify 的 `danceability` 是 0–1 的标准化分数，不能与 Essentia 的 0–3 直接比较。

---

### 4. Key（主调音名）

- **含义**：音乐的主音（.Root note）。
- **范围**：12 个音  
  `C, C#, D, D#, E, F, F#, G, G#, A, A#, B`
- **示例**：`"C#"` 表示主音为 C#。

---

### 5. Scale（调式）

- **含义**：音阶类型，决定情绪色彩。
- **常见值**：
  - `"major"`：大调，通常明亮、开朗
  - `"minor"`：小调，通常忧郁、内敛、紧张
- **示例**：`"minor"` 表示小调。
- **C# + minor**：C# 小调，情绪偏暗、感性或紧张。

---

### 6. Key Confidence（调性识别置信度）

- **含义**：Key / Scale 估计的可靠程度。
- **范围**：约 **0 – 1**，越大越可靠,小于0.3不可靠。
- **示例**：`0.84` 表示约 84% 可信度，较可靠。

---

### 7. Duration（分析时长，秒）

- **含义**：本次参与分析的音频长度（秒）。
- **范围**：0 – `MAX_ANALYSIS_SECONDS`。
